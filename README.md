# Autonomous Mobile Robot - PIC16F877A

This project is an autonomous mobile robot built using the PIC16F877A microcontroller.

requested phases :
- Line following using IR sensors
- Tunnel detection using LDR and ADC
- Obstacle and wall detection using ultrasonic sensors
- Motor control using PWM
- Start button using external interrupt
- 3-second startup delay using Timer0
- Servo motor flag raising at the parking stage

## Microcontroller
PIC16F877A

## Compiler
mikroC PRO for PIC
